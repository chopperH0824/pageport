CORE WORKFLOW & CAPABILITIES

把时间留给内容，不是重复排版

告别在网页编辑器里反复调整表格宽度与上传零散图片。PagePort 把本地写作的流畅度与企业内网 Wiki 的严谨发布结合在同一个桌面窗口。

多格式导入与本机文件写回

支持 .md、.docx、旧版 .doc、.html 及 Confluence 导出的 MIME Word 文件。Markdown 与纯文本可直接保存写回原文件，Word/HTML 编辑后可一键另存为干净的 Markdown。 查看钉钉在线文档导入指引。

Mac 旧版 DOC 用 textutil；Windows 旧版 DOC 请先另存为 DOCX

Confluence 原生宏与复杂表格

内置正文目录 [TOC]、五色状态胶囊（Status 宏）、四类信息提示面板（Info / Tip / Note / Warning），发布时直接转为 Confluence 原生宏。完整保留合并单元格、表格百分比宽度与单元格底色。

原生 Storage Format 宏转换 · 非静态截图

模块化工具栏与快捷排版

按常用、插入、排版与全部工具切换，提供字号、文字颜色、高亮、表格底色、格式刷、多级缩进、特殊符号、日期、查找替换（macOS ⌘F / Windows Ctrl+F）与实时字数统计。

源码视图与可视化视图毫秒级双向同步

备份先行 + 版本锁防覆盖

每次发布前强制拉取线上原页面保存至本机备份目录，并检查版本号冲突与行内评论。要求手动输入或核对页面标题二次确认，发布后自动回读线上正文，核对字数、表格、行与图片数量。

Mac：~/Library/Application Support/PagePort/data/backups · Windows：%APPDATA%\PagePort\data\backups

本地与内嵌图片哈希归档

自动提取 Word 内嵌图片或关联本地 PNG / JPEG / GIF / WebP，校验真实文件签名后以内容哈希命名上传为 Confluence 页面附件。遇到缺失图片自动阻断发布，防止将破损占位符发到线上。

单图 ≤ 6 MB · 最多 24 张配套图片

零云端中转的本机隐私边界

桌面版仅在随机 Loopback 端口运行，每次启动生成独立访问令牌。文档在本机转换，账号密码仅存在于当前会话内存。检查与发布时直连你指定的 HTTPS Confluence，不经第三方发布服务器中转。

Electron 沙箱隔离 · 退出应用即销毁会话
TRANSPARENT BOUNDARIES

格式兼容矩阵与安全发布准则

PagePort 追求可预期的工程可靠性，明确告知每一类内容在线上的真实转换行为，不伪装不支持的格式。

正文目录 [TOC]、状态胶囊、提示面板 原生宏 转换为 Confluence 原生 toc、status 及 info/tip/note/warning 宏。

只更新指定已有页面，绝不乱建或移动页面

发布模式始终为「替换指定目标页完整正文」，不会修改页面 ID、父子层级或访问权限。若检测到线上页面含有未处理的行内评论，将主动拒绝覆盖以保护团队讨论。

凭据零持久化，修改正文立即失效旧确认

Confluence 账号密码仅存在于当前内存，发布完成后自动清空。核对目标页后若再次修改正文，发布确认状态会立即重置，杜绝“看的是旧预览、发的是未核对新稿”。

首次使用建议在个人测试页验证

本地预览为高还原度的近似样式，而非 Confluence 官方渲染器。首次接入企业 Confluence 时，建议先在个人空间测试页体验完整备份与发布流程。

DINGTALK

钉钉在线文档，带到 Confluence

无需配置钉钉密钥。选择复制正文，或导出本地文件后导入。

复制正文并粘贴

在有访问权限的钉钉文档中选中正文并复制，切回 PagePort 空白工作区粘贴；已有文档时可直接粘贴到编辑器。请复制正文而不是分享链接。按复制内容中保留的结构识别标题、提示块、任务、状态及表格。

导出 Word 或 Markdown

在钉钉文档菜单中选择导出为 Word（.docx）或 Markdown（菜单因版本或权限可能不同），将文件拖入 PagePort。解压导出包后，Markdown 与配套图片一并导入。无法导出时请向文档所有者申请权限。

核对图片与特殊内容

不会读取钉钉登录态、自动抓取链接或下载私有图片。缺失图片需手动补充；带认证或时效的图片地址不代表已归档。公式、流程图、附件、评论和专有组件不保证还原，复杂表格与宏请先在独立测试页核对。

INSTALL

macOS 与 Windows 分别这样打开

macOS 与 Windows 安装包均未代码签名。请先核对 SHA-256，再按系统提示允许运行，不要关闭系统安全保护。

macOS

Apple Silicon · 拖入应用程序

  1. 打开 DMG 下载 PagePort-0.5.0-arm64.dmg，把 PagePort 拖入「应用程序」。当前没有 Intel 安装包。
  2. 首次允许打开 确认安装包来源与摘要后，若提示未能验证开发者，到「系统设置 → 隐私与安全性」选择「仍要打开」。
  3. 连上内网即可发布 不用单独安装 Go 或 Mark。菜单「PagePort → 打开备份文件夹」可查看本机原稿。
Windows

x64 安装向导 · 保留原有数据

  1. 运行安装程序 下载 PagePort-0.5.0-x64-setup.exe。默认装给当前用户，在所选位置自动创建 PagePort 文件夹；已选择同名文件夹时不会重复嵌套。没有 Windows ARM64 包。
  2. SmartScreen 提示时先核对 可能显示未知发布者。对照本页 SHA-256 后再选「仍要运行」。不要关闭系统安全保护。
  3. 不用额外运行时 不需要安装 Go、Node 或 Word。数据在 %APPDATA%\PagePort\data，更新时保留。真正的旧版二进制 DOC 请先另存为 DOCX。
