# PagePort 0.3.0

- 编辑工具栏新增“插入目录”，目录可放在正文光标位置。
- 本地目录随章节标题变化更新，支持点击跳转及 1–6 级标题范围设置。
- 源码支持独立一行 `[TOC]`；导出保留目录及层级设置，代码块不受影响。
- 发布时生成 Confluence 原生 TOC 宏，由 Confluence 生成线上目录。
- 保持原有整篇正文替换、版本检查、备份及确认机制，不增加隐式追加或章节合并。

17 项自动化测试通过，新增独立 Mac 测试流程覆盖目录插入、源码保留、
标题更新、撤销和发布预览。没有向真实公司页面写入内容。

本地预览不是 Confluence 官方渲染器，原生目录宏在目标企业实例的最终效果仍需测试页验证。
Apple Silicon 版本，应用未进行 Apple 开发者签名和公证。
