# PagePort 0.2.0

本地可视化编辑版本，面向 Apple Silicon Mac。

- 直接在预览正文中编辑，并与 Markdown 源码同步。
- 增加六级标题、文字样式、任务列表、引用、链接、图片、对齐及表格工具。
- 表格支持增删行列、表头、合并和拆分；增加大纲与专注模式。
- 支持本地图片选择、粘贴和拖入，以及 Markdown 导出。
- 保留撤销重做；未导出修改在关闭和替换时提醒。
- 编辑后立即失效旧发布确认，同步失败时阻止发布旧稿。
- 保留原有发布前备份、版本冲突检查和正文回读。

不是完整 Typora 替代品：公式、Mermaid、脚注、目录宏、分页和代码语法高亮暂不支持。
预览为近似样式，不保证任意 Word / HTML 逐像素无损。
复杂表格及扩展样式使用 HTML 混合 Markdown 保存。

验证：15 项自动化测试通过，浏览器编辑交互与窄屏检查通过，打包 Mac 应用启动检查通过。
本次没有向真实公司 Confluence 页面执行发布。

应用未使用 Apple 开发者证书签名、公证。首次打开请遵循系统“隐私与安全性”提示，
不要关闭系统整体安全保护。文档和密码在本机处理，仅发布到用户明确选择的 Confluence。
