# PagePort 0.4.0

## 新增

- Mac 与 Windows 共用 GitHub Release 更新检测：启动检查、每 6 小时检查、菜单和工具栏手动入口。
- 新版本标记、发布日期与更新说明；可关闭自动检查。离线失败不影响编辑和发布。
- 按系统和架构匹配安装包，下载进度、文件大小与 SHA-256 校验；校验后在 Finder/资源管理器查看，安装由用户确认。
- Windows x64 NSIS 安装程序，默认按用户安装，支持选择目录，保留应用数据。
- Windows 内置从校验过的 Mark 16.22.0 官方源码构建的引擎；用户无须另装运行时。
- Windows CI 覆盖转换、编辑、目录、搜索、窄窗口、更新界面、打包及隔离安装后启动。

## 本轮一并交付的编辑与导入改进

- 原生文件打开、刷新、关闭和保存；MD/TXT 可写回，Word/HTML 编辑结果另存为 Markdown。
- Mac 旧版 DOC/WPS 转换，Office 中文标题、大纲、文本框与中文/特殊编号兼容。
- Confluence 网页导出的 Word：表格底色、对齐、百分比宽度、勾选与原图地址保留。
- 无法转换的内嵌图片显示占位和警告；文档栏与发布栏可收起并拖动调整宽度。

## 更新与兼容边界

- 0.3.x 用户需先手动安装一次 0.4.0，之后可收到更高正式 Release 的更新提醒。
- 检测不是远程推送服务；应用打开且能连接 GitHub 时检查，仅推送源码不产生更新提醒。
- 不静默替换、强制退出或自动重启。请先保存文档并正常退出后安装；本机备份目录保留。
- Mac 当前提供 Apple Silicon DMG；Windows 提供 x64 EXE，不含 Windows ARM64 原生包。
- Mac 尚无 Apple Developer ID 签名/公证；Windows 尚无代码签名，系统可能提示未知发布者。不要关闭系统安全保护。
- Windows 真正的旧二进制 DOC/WPS 需先另存为 DOCX；Confluence 网页 Word 和 DOCX 结构的 WPS 可直接导入。
- 近似预览不等于 Confluence 官方渲染；远程原图可能需要站点认证，不自动归档。
- 没有向真实 Confluence 页面执行本轮测试写入。

安装包与摘要以本 Release 附件为准。发布时核对 tag、源码提交、版本、大小与 SHA-256。
