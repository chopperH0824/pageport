# PagePort 0.7.0 · 2026-11-02

- 修复左侧目录定位：从编辑、发布预览、源文件、检查项均可跳到对应标题。
- 本地保存新增原生 DOCX、Word 兼容 DOC（MHTML，非旧版二进制 DOC），保留 Markdown。
- 已载入的本地图片随文件内嵌保存；DOCX 逐张核对摘要及正文引用。缺图、不支持的图片或仅有远程地址时阻止导出并提示补图，不自动抓取远程内容。
- 移除固定导入文件体积、单图大小和图片数量上限，实际规模取决于设备资源；保留加密与异常压缩包检查、并发和超时保护。
- Word 保存默认另存，不自动覆写原件；文件先完整写入临时文件，再替换目标，避免保存失败时截断原文件。
- 修复 Confluence 网页导出 Word 的通用内嵌附件：按 `Content-Location`、`Content-ID` 和图片真实格式恢复本地图片，不再误报“尚未上传”。
- 新增 macOS / Windows 解压即用本地浏览器网关：无需安装、管理员权限或额外运行环境，保留导入、编辑、带图保存和受保护发布。
- 官网增加免安装入口、系统切换、ZIP 下载及校验摘要。首次需手动启动网关，不注册自启动、不绕过公司白名单。
- 网关仅监听随机本机端口，启动链接两分钟有效且单次使用，配合 HttpOnly 会话、来源与 CSRF 校验；数据与桌面版隔离。

# PagePort 0.1.0

首个 macOS 本地版本（Apple Silicon）。

- 内置 Mark 16.22.0，无需单独安装命令行工具。
- 导入 Markdown、HTML、Word .docx 与纯文本。
- 本地近似 Confluence 预览、文本修改、配套图片检查。
- 使用账号密码更新指定的已有页面，不保存公司密码。
- 目标页检查、原文备份、版本冲突保护、标题二次确认。
- 发布后回读核对文字和表格、行、图片数量。
- 本机随机端口与每次启动私密凭证，普通网页无法访问应用后端。

## 使用

打开 DMG，将 PagePort 拖入“应用程序”，然后启动。
导入文档并核对预览，填写目标页链接和公司账号密码，
点击“检查目标页面”，核对标题后再确认发布。
首次请使用独立测试页，不要直接覆盖正式需求文档。

## 已知边界

应用尚未通过 Apple 开发者签名或公证。首次启动可能需要在系统设置
“隐私与安全性”中允许打开，请勿关闭系统整体安全检查。

Mac 必须能够访问目标 Confluence。只支持服务端允许的 Basic Auth；
验证码、SSO 或账号策略可能阻止认证。

预览不是官方渲染器，不保证字体、分页、复杂 Word 排版和专有宏无损。
代码块使用无高亮的纯文本兼容显示。
只更新已有页面，替换完整正文，不合并原内容；检测到行内评论时阻止覆盖。

自动化验证包含真实 Mark 转换、模拟 REST 发布流程和打包应用启动。
未使用真实公司账号自动覆盖线上文档。

依赖审计尚有 Mammoth CLI 依赖链的一项中等风险公告（3 个依赖条目），
应用使用库接口，不调用该 CLI；详细边界见 SECURITY.md。
