# PagePort 0.5.0

## 全新品牌与工作区

- 采用“双页之桥”图标，统一桌面应用、导航、更新面板与官网标志。
- 蓝色用于编辑与选中状态，青绿用于发布与安全状态，正文维持白色纸面。
- 优化顶部品牌区、文档栏、格式工具、目录、发布面板及设置的视觉层次。
- 窄文档栏的文件信息不再逐字换行；保留拖动调整、收起侧栏和专注模式。
- 启动进入空白工作区，不再自动加载随包文稿；旧内置文稿已移除，仅按需打开公开虚构的格式示例。
- 编辑工具按常用、插入、排版与全部工具切换，新增字号与表格单元格底色控制。
- Windows 安装器在所选目录下自动创建 PagePort 文件夹，避免散落安装文件。

## 下载官网

- 采用居中标题、浅色背景、独立系统入口与清晰的下载区。
- 选择 macOS 或 Windows 不会触发下载；同一个下载按钮同步显示对应文件、大小和 SHA-256。
- 保留四步交互演示、安装指南、兼容边界与发布说明，兼顾桌面和手机。

## 不变的安全边界

- 增加在线文档富文本粘贴：显式提示块、状态标签与勾选任务映射为原生结构；不猜测无语义的装饰颜色。
- 增强 Word / Markdown 导入，恢复支持的语义样式、勾选字符与 Word 表格底色；钉钉不同版本仍需核对。
- 官网增加钉钉复制与导出指引，不支持通过分享链接自动抓取，不读取钉钉登录态或自动下载私有图片。
- 移除 `.wps` 格式入口与转换支持，请先另存为 `.docx`。

- 保留导入、编辑、原生宏、自动备份、版本冲突保护及发布后回读核验。
- 保留正文编辑样式，不向真实 Confluence 页面自动写入。
- 文档和账号不经第三方发布服务器；更新安装保留本机数据。
- macOS Apple Silicon 与 Windows x64 安装包仍未代码签名，请核对官方来源和 SHA-256。
